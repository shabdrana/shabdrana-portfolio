# Shabd Rana Portfolio

## Upload to a NEW GitHub repository
1. Create a new **Public** GitHub repository named `shabd-portfolio`.
2. Do not add a README, .gitignore, or license during creation.
3. Extract this ZIP.
4. Upload **everything inside this folder** to the root of the GitHub repository.
5. The repository root must contain `index.html`, `style.css`, `script.js`, and the `assets` folder.
6. In Vercel, import the `shabd-portfolio` repository and click Deploy.

## Required structure
```
index.html
style.css
script.js
README.md
assets/
  profile.png
  Shabd-Rana-CV.pdf
  certificates/
    cybersecurity-awareness.png
    saylor-database.png
    time-management.png
    ai-infosys.pdf
```

Do not move or rename the files inside `assets` because the HTML uses these exact relative paths.
